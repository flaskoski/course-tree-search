# Course Tree Search

App to search for an array of courses from an endpoint and display in a tree-like form

## Getting started

 - Clone this library
 - Make sure you have Node version 20.19+ or 22.12+
 - Run `npm install` to install vite's local server
 - Run `npm run build` to generate a compressed version of the project
 - Run `npm run preview` to start the local server and test the application at `localhost:4173`
